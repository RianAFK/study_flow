# 📚 Aplicativo de Estudos ENEM

Aplicativo desenvolvido para auxiliar estudantes na preparação para o **ENEM**, oferecendo acesso a questões e conteúdos de provas anteriores por meio da **API do ENEM**.

## 🎯 Objetivo

O objetivo do aplicativo é facilitar os estudos para o ENEM, permitindo que o estudante pratique questões, acompanhe seu desempenho e tenha uma experiência de estudo mais organizada.

## 🚀 Funcionalidades

* 📖 Acesso a questões de provas anteriores do ENEM
* 🔎 Pesquisa e filtragem de questões
* 📝 Resolução de questões
* ✅ Verificação das respostas
* 📊 Acompanhamento do desempenho
* 📱 Interface adaptada para dispositivos móveis
* 🌐 Consumo de dados através da API do ENEM

## 🔌 API do ENEM

O aplicativo utiliza uma API para obter informações relacionadas às provas e questões do ENEM, evitando a necessidade de armazenar todo o conteúdo diretamente no aplicativo.

## 📥 Instalação

1. Baixe o arquivo `.apk` do projeto.
2. Transfira o arquivo para o dispositivo Android.
3. Instale o aplicativo.
4. Abra o aplicativo e comece a estudar.

> Dependendo das configurações do dispositivo, pode ser necessário permitir a instalação de aplicativos de fontes externas.
